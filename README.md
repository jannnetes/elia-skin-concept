# Elia Skin Concept

Beauty & skincare website concept with Instagram-inspired branding.

## Live Demo

https://elia-skin-concept.netlify.app/

## About

Elia Skin Concept is a fictional skincare brand website created as a frontend portfolio project.

The idea was to build not only a website, but a full visual concept for a beauty brand: soft aesthetics, clean layout, skincare atmosphere, and Instagram-style branding.

## What I created

- brand idea
- website concept
- responsive landing page
- visual style
- skincare-focused UI
- Instagram-inspired moodboard

## Features

- modern landing page
- responsive layout
- smooth animations
- clean beauty-style design
- sections for services, routine, gallery and booking

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
